## 复跑办法（任何人可核对）

```bash
cd <本目录>
mkdir -p dist
npm run check && npm run scan:sensitive      # 语法 + 脱敏扫描
node scripts/selftest.mjs                    # 81 项离线自检
npm pack --pack-destination dist
sha256sum dist/dsh-window-size-keeper-0.1.0.tgz   # Windows: certutil -hashfile dist\...tgz SHA256
tar tzf dist/dsh-window-size-keeper-0.1.0.tgz     # 11 个文件，必须与上表一一对应
```

## owner / 署名 / 推送路线（2026-10-19 定稿）

仓库在 **`ecbob`** 这个 GitHub 账号下（项目创建人即本仓库作者），所以包与文档里的 owner、`author`、
`LICENSE` 版权行、投稿条目文件名与 `url:`/`name:` 全部写 `ecbob`，不再出现别的 handle。

本机推送走 **SSH**：`git remote add origin git@github.com:ecbob/dsh-window-size-keeper.git` + `push -u origin main`。
前提是账号里加着本机 `~/.ssh/id_ed25519.pub`；本机实测过——没加时 **22 端口与 443 端口都回
`Permission denied (publickey)`**（网络是通的，卡的是授权）。22 被网络拦时在 `~/.ssh/config` 里给
`github.com` 配 `Hostname ssh.github.com` + `Port 443`。HTTPS + 个人访问令牌是替代路线（GitHub 不收账号密码）。

提交身份建议：`ecbob <ecbob@users.noreply.github.com>`（挂账号、不暴露个人邮箱）。
